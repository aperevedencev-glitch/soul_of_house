# Soul of Home

Мастерская и школа ручной работы: новогодние шары, обучение, бесплатные уроки об уюте.

| Папка | Что внутри |
|---|---|
| `docs/` | Сайт. Отсюда его раздаёт GitHub Pages; для другого хостинга загружайте содержимое папки целиком |
| `soulhome-bot/` | Telegram-бот @SoulHomeRuBot с автоворонкой для компаний |
| `archive/` | Старая версия сайта (не используется) |

Подробнее о сайте — в `SOUL-OF-HOME.md`, о боте — в `soulhome-bot/README.md`.
