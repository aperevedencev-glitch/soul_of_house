# Soul of Home

Мастерская и школа ручной работы: новогодние шары, обучение, бесплатные уроки об уюте.

| Папка | Что внутри |
|---|---|
| `site-src/` | **Исходники страниц** (`pages/*.html`) и сборка `build.py`: шапка, подвал, `<head>`, sitemap — общие для всех страниц |
| `docs/` | Готовый сайт. Отсюда его раздаёт GitHub Pages; стили, скрипты, картинки и шрифты правятся прямо здесь |
| `deploy/reg.ru/` | Упаковка сайта для reg.ru: `.htaccess`, приём заявок `api/lead.php`, `build.sh домен` |
| `soulhome-bot/` | Telegram-бот @SoulHomeRuBot с автоворонкой для компаний |
| `archive/` | Старая версия сайта (не используется) |

Подробнее о сайте — в `SOUL-OF-HOME.md`, о боте — в `soulhome-bot/README.md`.

## Как менять сайт

| Что поменять | Где |
|---|---|
| Текст или блок на странице | `site-src/pages/<страница>.html`, затем `python3 site-src/build.py` |
| Меню, подвал, заголовки вкладок, описания для поиска, новая страница | таблица `PAGE_TABLE` в `site-src/build.py`, затем сборка |
| Цвета, отступы, анимации | `docs/styles.css` (сборка не нужна) |
| Поведение (слайдер, формы, таймер, Нейрокот) | `docs/site.js` (сборка не нужна) |

HTML-файлы в `docs/` генерируются — правки в них напрямую затрутся при следующей сборке.
После изменения стилей или скриптов увеличьте `VERSION` в `docs/sw.js`, чтобы установленное приложение обновилось.
Для reg.ru: `./deploy/reg.ru/build.sh https://ваш-домен.ru`.
