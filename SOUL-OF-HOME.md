# Soul of Home — сайт мастерской

Сайт мастерской и школы ручной работы: коллекция новогодних шаров, обучение, бесплатные уроки и ИИ-помощник Нейрокот.

Страницы: `index.html` (главная), `raboty.html` (мои работы), `obuchenie.html` (обучение), `uroki.html` (уроки).
Общие стили — `styles.css`, скрипты — `site.js`, изображения — `img/`.

Сайт статический: его можно открыть через GitHub Pages или любой хостинг, загрузив папку целиком.
Чат с Нейрокотом отвечает через ИИ только внутри claude.ai; на обычном хостинге он предлагает написать в Telegram-бот @SoulHomeRuBot.
Код бота — в папке `soulhome-bot`. Для хостинга загружайте содержимое папки `docs/` целиком.

Аналитика: номер счётчика Яндекс.Метрики и ID потока GA4 вписываются в `docs/analytics-config.js` — один файл на все страницы.

Домен: в `sitemap.xml` и `robots.txt` указан адрес GitHub Pages `https://aperevedencev-glitch.github.io/soul_of_house`. При переезде на свой домен замените его.
