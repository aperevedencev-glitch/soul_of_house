# Soul of Home на хостинге reg.ru

## Сборка
```bash
./deploy/reg.ru/build.sh https://ваш-домен.ru
```
Берёт готовый сайт из `docs/`, подставляет домен в canonical, og:url, og:image, sitemap.xml и robots.txt,
добавляет `.htaccess` и `404.html`. Результат — `public_html/` и `soul-of-home-regru.zip` (в git не попадают).

## Загрузка
1. reg.ru → Хостинг → заказать тариф (подходит самый простой, «Host-0/Host-A»), привязать домен.
2. **SSL:** Домены и услуги → домен → SSL-сертификат → бесплатный Let's Encrypt (или «SSL в подарок»).
   Без https не заработают установка на телефон (PWA) и офлайн-режим.
3. Панель хостинга (ISPmanager) → Менеджер файлов → папка `www/ваш-домен.ru/`.
   Удалить заглушку `index.html` от reg.ru, загрузить архив → «Извлечь». В папке должны лежать
   `index.html`, `.htaccess`, `img/`, `fonts/` — без вложенной папки.
   Альтернатива — FileZilla по FTP/SFTP (данные доступа — в письме reg.ru / в панели «FTP-пользователи»).
4. Проверить: `https://ваш-домен.ru`, `http://` и `www.` должны перенаправлять на https без www,
   `https://ваш-домен.ru/несуществующая` — страница 404.
5. Яндекс.Вебмастер и Google Search Console: подтвердить сайт, отправить `https://ваш-домен.ru/sitemap.xml`.
6. Вписать номера счётчиков в `analytics-config.js` (можно прямо в менеджере файлов).
7. Бот: в `.env` на сервере бота обновить `SITE_URL=https://ваш-домен.ru`, затем `sudo systemctl restart soulhome-bot`.

## Обновления сайта
Пересобрать → залить изменённые файлы поверх. Если менялись стили/скрипты — увеличить `VERSION` в `sw.js`,
иначе телефоны с установленным приложением увидят обновление только со второго захода.

Пароли от reg.ru и FTP в чат, репозиторий и файлы сайта не вставлять.
